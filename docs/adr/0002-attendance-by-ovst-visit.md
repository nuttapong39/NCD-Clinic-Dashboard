# ตัดสินการมาตามนัดจาก visit ใน ovst ไม่ใช่สถานะนัด

นัดจะนับเป็นมาตามนัดเมื่อมีแถวใน `ovst` ของ HN เดียวกันตรงวันนัด (`ovst.vstdate = oapp.nextdate`) แทนการใช้ `oapp_status_id = 2` เพราะเจ้าหน้าที่ไม่ได้อัปเดตสถานะนัดทุกครั้ง ทำให้นัดที่ผู้ป่วยมาจริงแต่สถานะยังเป็น 1 หลุดจากทั้งกลุ่ม "มา" และ "ยังไม่มา" และยอดรวมไม่ลงตัว เกณฑ์นี้ทำให้ มาตามนัด + ยังไม่มา/ขาดนัด = นัดทั้งหมด เสมอ

สถานะนัดยังใช้เพื่อตัดนัดที่ยกเลิกหรือเลื่อนออก โดยนับเฉพาะ `oapp_status_id IN (1, 2)` (ทีม IT ต้องยืนยันรหัส)

## Consequences

- ผู้ป่วยที่มารับบริการแผนกอื่นในวันนัดนับเป็นมาตามนัด
- ผู้ป่วยที่มาช้าหรือเร็วกว่าวันนัดหนึ่งวันนับเป็นขาดนัด
