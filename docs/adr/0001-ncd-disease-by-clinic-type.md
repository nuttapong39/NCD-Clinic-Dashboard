# แยกโรค DM/HT ตามประเภทคลินิก ไม่ใช่การวินิจฉัย

แดชบอร์ดนับนัดเป็นเบาหวานหรือความดันจาก `hosxp_clinic_type.moph_ncd_code` ของคลินิกที่นัด (`001` = DM, `002` = HT) แทนการดูรหัส ICD-10 ของผู้ป่วยหรือทะเบียน `clinicmember` เพราะรหัสกลางของ สธ. ใช้ได้กับทุกโรงพยาบาลโดยไม่ต้องตั้งค่ารหัสคลินิกภายใน ซึ่งจำเป็นสำหรับแอปบน HOSxP Marketplace และตรงกับ query ที่ทีม IT ส่งมา

## Consequences

- โรงพยาบาลที่มี "คลินิก NCD รวม" ผูกกับประเภทเดียว จะเห็นนัดทั้งหมดอยู่ในโรคนั้น และอีกโรคเป็นศูนย์ ต้องอธิบายไว้ใน callout ของ modal
- ผู้ป่วยที่เป็นทั้งสองโรคถูกนับตามคลินิกที่นัด ไม่ถูกนับซ้ำในทั้งสองโรค เว้นแต่มีนัดทั้งสองคลินิก
