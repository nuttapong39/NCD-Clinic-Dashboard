# ชุดสีที่คนตาบอดสีแยกได้ และสงวนสีให้ DM/HT

UI-TEMPLATE กำหนดสีหมวดเป็น sky / indigo / teal แต่เมื่อตรวจด้วย `validate_palette.js` (dataviz skill) คู่ sky กับ indigo ซึ่งต้องใช้แยก DM กับ HT ห่างกันเพียง ΔE 2.9 สำหรับผู้ที่ตาบอดสีเขียว-แดง (เกณฑ์ ≥ 8) จึงเปลี่ยนเป็นชุดสีที่ผ่านการตรวจ และสงวนสีน้ำเงิน (`--cat-1`) ให้ DM กับสีส้ม (`--cat-2`) ให้ HT เท่านั้น คลินิกและกลุ่มสิทธิใช้ `--cat-3` ถึง `--cat-7` (aqua, yellow, magenta, green, violet) ตามลำดับคงที่ ไม่วนสีซ้ำ

## Consequences

- กราฟคลินิกแสดงได้ไม่เกิน 5 สี ถ้า รพ. มีคลินิก NCD มากกว่า 5 แห่ง จะแสดง 4 คลินิกแรกตามลำดับ (DM ก่อน แล้วตามรหัสคลินิก) และรวมที่เหลือเป็น "คลินิกอื่น ๆ" สีเทา ซึ่งคลิกเปิด modal ไม่ได้
- สีน้ำเงินหรือสีส้มบนหน้าจอหมายถึง DM หรือ HT เสมอ
- สีส่วนใหญ่มีความต่างกับพื้นขาวต่ำกว่า 3:1 จึงต้องมี legend, tooltip และตารางรายเดือนประกอบทุกกราฟ
